# 🧠 Mental Maths Timer (MMQ Timer)

A simple and powerful timer designed for Mental Maths Question (MMQ) practice.

## ✨ Features

* ⏱️ High-precision timer (milliseconds)
* 🎯 Multiple target times:

  * 25 seconds
  * 20 seconds
  * 15 seconds
  * 10 seconds
  * 5 seconds
* 🔔 Automatic sound alert when the selected time limit is reached
* 📝 Automatic question logging
* ✍️ Answer boxes for each question
* ⌨️ Spacebar shortcut for Start/Stop
* 🗑️ Delete individual entries
* ↩️ Undo last deletion
* 🧹 Clear all entries
* 🔢 Automatic question renumbering

## 🚀 How to Use

1. Open `Timer.html` in your browser.
2. Select a target time.
3. Press **Start** or the **Spacebar**.
4. Solve your mental maths question.
5. Press **Stop** or the **Spacebar** when finished.
6. Enter your answer in the answer box.
7. Review the recorded time.

## ⌨️ Keyboard Shortcuts

| Shortcut           | Action                |
| ------------------ | --------------------- |
| Spacebar           | Start / Stop Timer    |
| Backspace          | Clear All Entries     |
| Backspace + Number | Delete Last N Entries |

## 📊 Recorded Data

Each attempt stores:

* Question Number
* Answer
* Completion Time

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)

## 🎯 Purpose

This project was created to help students practice Mental Maths Questions (MMQ) while accurately tracking solving time and recording answers.
Also helps students pratice for other quizes.
